2026 · Agent autonome

🏦 Agent IA de traitement de dossiers

Client : SAMAT-I · credit-on-line, comparateur de crédit en France (courtage / rachat de crédit)

Défi : Le back-office signale les fiches clients incomplètes ou en erreur par un voyant rouge. Les traiter à la main (ouvrir, vérifier, compléter, valider) mobilise plusieurs heures par jour sur une tâche purement répétitive.

Solution : Un agent Python autonome qui pilote le back-office, détecte les fiches en erreur, lit les champs déjà remplis, complète les informations manquantes puis valide. La logique métier repose sur des règles et conditions Python, renforcées par un LLM (Claude) pour interpréter les cas ambigus. 100 % en local, avec journaux complets et rapport de traitement.

Python Playwright Règles & conditions Python LLM · Claude Automatisation back-office
Résultats
  • ✅ 700+ dossiers traités
  • ⏱️ ~4 h de travail économisées par jour
  • 📈 Capacité de financement client augmentée
  • 🔒 100 % local, aucune donnée sur serveur externe
  • 🧾 Exécution supervisée + journaux complets
